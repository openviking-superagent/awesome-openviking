## 官方资源

- **[OpenViking](https://github.com/volcengine/OpenViking)** — 面向智能体的上下文数据库，用 `viking://` 统一管理记忆、知识和技能。
- **[开发文档](https://docs.openviking.ai/zh/)** — 概念、快速开始、API 与接入指南。
- **[智能体接入](https://openviking.ai/integrations)** — 连接 Claude Code、Codex、Cursor、OpenCode、DSH 等工具。
- **[SDK](https://github.com/volcengine/OpenViking#sdks)** — Python、Go、TypeScript 与 HTTP API。
- **[官方博客](https://blog.openviking.ai/)** — 工程实践、产品动态与团队思考。

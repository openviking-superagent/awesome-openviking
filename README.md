## Contributing

Know a project, plugin, tutorial, or real-world use case that belongs here? **[Open a pull request](https://github.com/openviking-superagent/awesome-openviking/pulls)**. Community experiments and production systems are both welcome.

A good entry tells people what it does, how it uses OpenViking, and where to try it. See the [contribution guide](CONTRIBUTING.md) for the short checklist.
